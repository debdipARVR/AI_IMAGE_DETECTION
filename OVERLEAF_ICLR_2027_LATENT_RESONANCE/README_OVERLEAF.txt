HOW TO USE IN OVERLEAF:
1. Go to https://www.overleaf.com/project
2. Click 'New Project' -> 'Upload Project'
3. Select 'OVERLEAF_ICLR_2027_LATENT_RESONANCE.zip' (or upload this folder directly).
4. In Overleaf project settings (top-left menu):
   - Compiler: pdfLaTeX
   - TeX Live version: 2024 (or later)
   - Main document: main.tex
5. Click 'Recompile'.

FOLDER CONTENTS:
- main.tex                  : Primary master manuscript with all ICLR critique revisions
- paper.tex                 : Duplicate manuscript mirror
- references.bib            : BibTeX bibliography (including DIRE, GenImage, LDM, etc.)
- iclr2027_conference.sty   : Official ICLR 2027 LaTeX style sheet
- iclr2027_conference.bst   : BibTeX author-year style definition
- figures/                  : High-resolution PNG forensic figures referenced in the paper:
    * publication_sota_graphic.png
    * forensic_diagnostic_panel.png
    * radial_power_spectrum_comparison.png

All propositions, LDM causality corrections, PRNU residual filters, baseline discussions,
and downstream perturbation metrics are fully integrated and verified.
